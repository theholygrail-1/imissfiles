# imissfiles

PDF and image tools that run in the browser tab. Nothing is uploaded.

Site: https://imissfiles.com

## Check it yourself

1. Open a tool
2. Open DevTools → Network
3. Drop a file in
4. If you see a POST about the size of your file, the claim failed

Guide: https://imissfiles.com/guides/check-if-a-website-uploads-your-file/
